# Practice solutions

## `chain_values`

One visit per node costs O(n) time. The result takes O(n) space and the walk uses O(1) extra space.

## `first_match`

The first node can match in O(1) time. A miss takes O(n) time. The walk needs O(1) extra space.

## `make_singly_linked_list`

Front insertion, append, and len take O(1) time. Search and removal by value take O(n) worst-case time and O(1) extra space. to_list takes O(n) time and output space. The nodes use O(n) storage.
