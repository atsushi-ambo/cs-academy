# Practice solutions

## `make_stack`

End operations take amortized O(1) time per call. Stored items take O(n) space.

## `make_two_stack_queue`

Each entry is pushed and popped a fixed number of times. Enqueue and dequeue take amortized O(1) time. A single transfer takes O(n) time. The stacks take O(n) space.

## `brackets_match`

The scan takes O(n) time. A string of only openers uses O(n) stack space.

## `make_ring_queue`

The fixed list takes O(capacity) time and space to build. Each operation changes O(1) slots and takes O(1) time and extra space.
