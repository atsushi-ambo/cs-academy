# Practice solutions

## `insert_after`

Link writes and a size increment cost O(1) time. Each insert adds one node and uses O(1) extra space.

## `remove_node`

The node gives both neighbors directly. Changing their links takes O(1) time and O(1) extra space.

## `check_chain`

The walk visits at most size nodes before rejecting an extra one. For a valid n-node chain, time is O(n) and extra space is O(1).
