# Practice solutions

## `sift_down_max`

Checking the larger child is enough to decide if the parent can stay. A sift takes O(log n) time and O(1) extra space.

## `move_max`

The move is constant time before the sift. The whole extraction takes O(log n) time and O(1) workspace.

## `heap_sort`

Bottom-up construction costs O(n) time. Moving n - 1 maxima takes O(n log n) worst-case time. The iterative code uses O(1) extra space.
