# Recursion ロードマップとの対応（2026-11-27 確認）

本人がログインした Chrome で recursionist.io/roadmap を見て、各コースの**トピック名とセクション名だけ**を拾い、このアプリの Unit に対応づけた。本文・説明文・問題はコピーしていない（[sources.md](sources.md) の区分 C）。

決まり:

- ロードマップのトピックは、必ずどこかの Unit で「解説 → 予想（四択）→ 自分で書く（テスト付き）→ 復習」まで学べるようにする。名前だけ触れて終わりにしない。
- アルゴリズムとデータ構造（★）は、実装を自分で書く Code ステップを必ず置く（再帰ならトレース・基底条件・計算量まで）。
- 言語は Python に統一する。フロントエンド・特定FW（Laravel など）の言語別コースは対象外。
- この表は「どの Unit で学ぶか」の対応だけを示す。教材ができているかは各 Unit の `unit.yaml` の `status`（なし＝目次だけ、`draft`＝作成中、`published`＝公開）で管理し、アプリの Path 画面に出す。目次だけの Unit は学習済みとみなさない。
- 並び順は前提を先にする: 再帰の基礎 → 分割統治 → マージソート・クイックソート、ヒープ → ヒープソート、メモリと配列 → 連結リスト。
